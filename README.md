# Scalable Telegram Search Platform

A production-ready, highly scalable platform for indexing and searching authorized datasets via Telegram.

## Features
- Scalable microservice-ready architecture (FastAPI, Aiogram, Celery, PostgreSQL, OpenSearch).
- Fully asynchronous bot and backend.
- Robust credit ledger and payment handling.
- Large-scale chunked dataset importing with resume/checkpointing capabilities.
- Zero-downtime dataset updates via OpenSearch aliasing.
- Bilingual Support (Persian/English).
